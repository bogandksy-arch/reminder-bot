# Бот-нагадування для Telegram

## 1. Отримати токен бота

1. У Telegram знайдіть **@BotFather**.
2. Надішліть `/newbot`, дайте боту ім'я та юзернейм (має закінчуватись на `bot`).
3. BotFather надішле токен виду `123456789:AAExampleTokenHere`. Збережіть його.

## 2. Встановити залежності

Потрібен Python 3.10+.

```bash
cd reminder_bot
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## 3. Запустити бота

```bash
export TELEGRAM_BOT_TOKEN="ваш_токен_від_BotFather"   # Windows: set TELEGRAM_BOT_TOKEN=...
python bot.py
```

Якщо все гаразд, у консолі з'явиться `Бот запущено.` — можна писати боту в Telegram.

## Команди

| Команда | Що робить |
|---|---|
| `/start` | Привітання й короткий приклад |
| `/help` | Повний список форматів часу |
| `/remind 10m Купити молоко` | Нагадати через 10 хвилин |
| `/remind 15:30 Зустріч` | Нагадати сьогодні (або завтра) о 15:30 |
| `/remind 25.12 10:00 Привітати` | Нагадати в конкретну дату |
| `/list` | Показати активні нагадування з їхніми id |
| `/cancel <id>` | Скасувати нагадування |

Нагадування зберігаються у файлі `reminders.json` поруч з `bot.py`, тому переживають перезапуск бота.

## Щоб бот працював постійно (24/7)

Зараз бот працює, поки запущений `python bot.py` на вашому комп'ютері. Щоб він працював завжди, потрібен сервер або хостинг, наприклад:

- **Railway** або **Render** (безкоштовні тарифи для невеликих ботів)
- **VPS** (наприклад, DigitalOcean, Hetzner) із `systemd`-сервісом або `screen`/`tmux`
- Raspberry Pi чи інший комп'ютер, що завжди увімкнений

Дайте знати, якщо потрібна допомога з розгортанням на конкретному хостингу.
